# Contributing

Thank you for looking. For now Ulune takes **issues, not code**.

- **Something wrong?** [Open an issue](https://github.com/ulune/ulune/issues/new/choose):
  a bug, a position that looks off, a sentence that reads badly in English or
  French.
- **An idea?** An issue too. Say what you would like to do with Ulune, rather
  than how to build it.
- **A security problem?** Never in an issue: see [SECURITY.md](SECURITY.md).

Pull requests can't be merged for now, however good they are. While all of
Ulune's code comes from one author, its licensing choices stay open; code from
others would tie them. This may change, and this file will say so.

## Keep people's data out of issues

Issues are public and stay public. Never post a real person's birth date, time
or place, a chart's name, or a screenshot showing them. To show a problem, use
the sample chart (1 January 2000, noon, Greenwich), an invented birth, or the
positions alone. If a problem only shows with a real birth, write to
limiel.ulune@protonmail.com instead.

## Running your own copy

The [README](README.md) says how to run, test and build Ulune. You are free to
change it and run your own copy under the [GNU AGPL](LICENSE): if people use
your changed version over a network, offer them its source code.
